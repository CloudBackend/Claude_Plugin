# XIOS/3 Icons Reference
Usage: `icon://name` or `icon://name?color=hex`

### Parameters
- `color` — hex color (without #) or named color: `icon://star?color=FF5722`
- `size` — pixel size: `icon://star?size=32`
- `theme` — icon theme override: `icon://star?theme=marble`
- `shadow` — drop shadow: `icon://star?shadow=true`

### Overlay (badge a second icon onto the first)
- `overlay` — overlay icon name: `icon://folder?overlay=star`
- `opos` — position (n, ne, e, se, s, sw, w, nw, c): `icon://folder?overlay=star&opos=ne`
- `ocolor` — overlay color: `icon://folder?overlay=star&ocolor=green`
- `osize` — overlay scale (0-1): `icon://folder?overlay=star&osize=0.5`

Combine freely: `icon://document?color=336699&overlay=add&opos=se&ocolor=orange&osize=0.5`

You can also use your own image paths instead of `icon://` — they just won't adapt to theme changes.

### Custom icon libraries
Create an XML icon library file mapped to a custom theme. View the built-in format with: `xmlpad xios/icons/ie-o.xml`
